Разрабатываю backend-сервисы и интеграции на Python: проектирую API, работаю с PostgreSQL и Redis, организую фоновые задачи и устойчивое взаимодействие с внешними системами.

Основной стек: **Python, FastAPI, Django, SQLAlchemy, PostgreSQL, Redis, Celery, Docker и GitHub Actions**.

## Избранные проекты

### [AI Contact Service](https://github.com/Tikhovskoy/ai-contact-service)

Асинхронный backend для формы обратной связи с AI-анализом и надёжной доставкой писем.

- FastAPI, SQLAlchemy, PostgreSQL и Redis
- transactional outbox и идемпотентность
- graceful fallback при недоступности AI
- структурированные ошибки, rate limiting и защита персональных данных
- CI, type checking, security audit и тестовое покрытие

### [Margin Guard](https://github.com/Tikhovskoy/margin-guard)

Сервис расчёта маржи для продавцов Wildberries и Ozon.

- расчёт маржи и выявление проблемных SKU
- FastAPI, PostgreSQL, Celery и Redis
- загрузка себестоимости из CSV
- web-dashboard и Telegram alerts
- Docker Compose, тесты и CI

### [RemnaWave VPN Orchestrator](https://github.com/Tikhovskoy/remnawave-vpn-orchestrator)

Backend-оркестратор для управления VPN-клиентами через RemnaWave.

- асинхронная интеграция с внешней системой
- управление жизненным циклом подписок
- аудит операций и обработка частичных сбоев
- FastAPI, SQLAlchemy, Alembic и PostgreSQL
